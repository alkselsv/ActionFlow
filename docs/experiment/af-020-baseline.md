# AF-020. Базовая оценка локальных детекторов

Команда из корня репозитория.

```powershell
$env:PYTHONPATH = 'backend/src'
uv run --project backend --frozen python scripts/evaluate_baseline.py
```

Скрипт создаёт отдельную временную базу в памяти на каждый из 12 утверждённых срезов AF-002. Он импортирует синтетический экспорт, применяет согласованный календарь и стороны участников, строит срез по фактической доступности сообщений на момент оценки и вызывает три Activity напрямую. Это новое исполнение. Replay Temporal воспроизводит решения workflow из записанной истории.

Эталон открытой ситуации задаётся типом и номером исходного сообщения. Один эталон соответствует максимум одному валидному кандидату. Повторные кандидаты на тот же тип и основание учитываются как дубли и ложные срабатывания. Исполненные и отменённые обязательства исключаются из оценки открытых ситуаций. Для совпавших кандидатов проверяются основание и допустимые номера свидетельств. SLA проверяется по состоянию, границе и времени первой реакции там, где эти значения размечены. Отчёт также показывает длительность и доступную стоимость по срезу и детектору. При неизвестной стоимости возвращается `null`.

| Набор | Тип | TP / FP / FN | Precision | Recall | Корректные основания |
| --- | --- | --- | --- | --- | --- |
| Разработка | Обращения | 4 / 0 / 0 | 100% | 100% | 3 / 4 |
| Разработка | Обязательства | 5 / 4 / 0 | 56% | 100% | 4 / 5 |
| Разработка | Претензии | 1 / 0 / 0 | 100% | 100% | 1 / 1 |
| Отложенная проверка | Обращения | 2 / 1 / 1 | 67% | 67% | 2 / 2 |
| Отложенная проверка | Обязательства | 3 / 0 / 0 | 100% | 100% | 3 / 3 |
| Отложенная проверка | Претензии | 1 / 0 / 0 | 100% | 100% | 1 / 1 |

В разработке обнаружен один дубль обязательства. Для шести совпавших обращений с размеченным SLA ошибок расчёта не обнаружено. Длительность зависит от машины. История экспорта ограничена наблюдёнными редакциями, что отражено в `input_limitations` каждого среза. Выборка синтетическая и мала. Отложенные чаты сохранены отдельно. [Правила и утверждённая разметка AF-002](af-002-annotation.md)

При технической приёмке AF-022 исправлено сопоставление `s-001`: №2 содержит обещание сотрудника, №3 подтверждает время со стороны клиента. До исправления этот случай учитывался как одно ложное срабатывание и один пропуск обязательства.
