# AF-025, часть 2. Диагностическая оценка выбранной конфигурации

Дата: 2026-11-23. Issue: [#25](https://github.com/alkselsv/ActionFlow/issues/25). Протокол: [AF-025](af-025-evaluation-protocol.md). Конфигурация выбрана в [AF-023 ч. 1](af-023-model-comparison.md).

## Вердикт

**Порог пилотной готовности не пройден.** Выполнен один детерминированный диагностический прогон на новом synthetic holdout v2 по прямому поручению владельца при неизвестной локальной стоимости. Это разрешение применимо только к диагностике: `cost_usd: null` остаётся непройденным gate AF-025, не является нулевой стоимостью и не допускает живой пилот.

Результат ограничен: чат-тексты и разметку создал агент; независимой человеческой разметки и репрезентативности реальных переписок нет. Первая сгенерированная версия v1 признана невалидной из-за cutoff-ошибки и в метрики не включена. Для v2 входы проверены и заморожены до прогона. Из-за низкой precision и рисков неполной агентской разметки метрики являются диагностическими, а не независимым доказательством качества на реальных данных.

## Зафиксированная конфигурация и набор

| Параметр | Значение |
| --- | --- |
| Dataset | `af025-synthetic-independent-v2` |
| Объём | 15 отдельных чатов, 45 сообщений, 5 размеченных карточек каждого типа |
| Источник / разметка | полностью synthetic, создано агентом до запуска, не проверено человеком |
| Разделение | новые chat IDs; пересечений с AF-002 нет |
| Cutoff | `2026-09-20T23:00:00Z`; все 45 сообщений доступны к cutoff |
| Model / detector | `local-baseline-unanswered-v1`; `local-unanswered-v3` |
| Prompt / rules | `unanswered-rules-v3` |
| Другие типы | `local-commitment-v1`, `local-complaint-v1` |
| Контекст | базовый; Cognee исключён по результату #23 «требует исправления» |
| Повторы | 1: локальные детекторы детерминированы; сравнение повторного SHA в этом прогоне не запускалось |
| Стоимость | внешний расход $0; локальная стоимость `null` (неизвестна) |

SHA-256 каждого fixture и разметки зафиксирован **до** запуска в [`frozen_manifest.json`](../../experiments/af025_independent/v2/frozen_manifest.json). Машинный результат: [`results.json`](../../experiments/af025_independent/v2/results.json). Генератор и валидатор: [`generate_dataset.py`](../../experiments/af025_independent/generate_dataset.py), [`freeze_dataset.py`](../../experiments/af025_independent/freeze_dataset.py); запуск: [`run_evaluation.py`](../../experiments/af025_independent/run_evaluation.py).

## Результаты

Метрики приведены как TP / FP / FN по фиксированной агентской разметке.

| Тип | TP / FP / FN | Precision | Recall | Валидные основания | Дубли | Критические пропуски | Порог |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| `unanswered` | 5 / 15 / 0 | 25% | 100% | 5/5 | 0 | 0 | **Не пройден**: precision < 80% |
| `commitment` | 5 / 10 / 0 | 33,3% | 100% | 5/5 | 0 | 0 | **Не пройден**: precision < 80% |
| `complaint` | 5 / 0 / 0 | 100% | 100% | 5/5 | 0 | 0 | Метрики пройдены на synthetic labels; перенос на реальные чаты не подтверждён |

SLA: **0 размеченных проверок**, поэтому порог ошибок SLA не оценён и не считается пройденным. Длительность анализа на локальном оборудовании: медиана 0,048 с, диапазон 0,035–0,210 с; это не эксплуатационный p95. `cost_usd` неизвестен во всех 15 запусках; стоимостный gate не пройден. Ограничения генерации/разметки и конфигурации также влияют на переносимость показателей.

## Решение и следующий цикл

Не допускать v3 к пилоту. В первую очередь разобрать 25 FP по `unanswered` и `commitment`, перепроверить полноту карточек в синтетической разметке и добавить SLA-сценарии. Не менять конфигурацию по этому набору и не переиспользовать v2 как независимый набор после анализа результатов. Для следующей независимой версии нужна новая, заранее размеченная выборка; по возможности разметку должен проверить доменный эксперт, а для бизнес-вывода нужна репрезентативная обезличенная выборка вне Git. Отдельно измерить или явно согласовать локальную стоимость по AF-025.
