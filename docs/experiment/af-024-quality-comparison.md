# AF-024, часть 2. Решение по сравнению качества Cognee

Дата: 2026-11-23. Задача: [#24](https://github.com/alkselsv/ActionFlow/issues/24). Предшествующая техническая проверка: [#23](https://github.com/alkselsv/ActionFlow/issues/23), [отчёт](af-024-cognee-context.md). Протокол: [AF-025](af-025-evaluation-protocol.md).

## Решение

**Сравнение качества отложено. Cognee не включается в базовую конфигурацию и не допускается к A/B-проверке.** Issue #24 завершается фиксацией допустимого результата «отложить», предусмотренного её условиями. Метрики прироста качества, стоимости и задержки Cognee в этом эксперименте не заявляются: проверка не проводилась, поскольку входная проекция не прошла технический gate #23.

## Основание

Отчёт #23 проверил изоляцию и жизненный цикл отдельной проекции, но обнаружил дефекты нативной памяти, влияющие на корректность сравнения контекста:

- запрос с датой сам по себе не обеспечивает фильтрацию по `as_of`;
- `update` оставляет `external_metadata` на старой редакции;
- результат `SUMMARIES` требует join по `source_chunk_id` для доказуемой привязки;
- graph completion без LLM-ключа не проверен;
- изоляция наборов зависит от access control; без него `datasets` не гарантирует разделение проектов.

При этих ограничениях нельзя гарантировать, что кандидат получает правильный исторический контекст, редакцию и основания для карточки. A/B-метрики смешали бы качество детектора с ошибками памяти, что прямо запрещено условиями #24 и протоколом AF-025. Сравнение не запускалось и результаты #23 не интерпретируются как оценка качества находок.

## Состояние критериев #24

| Критерий | Статус | Основание |
| --- | --- | --- |
| Зафиксировать одинаковые детектор, модель, prompt, правила, входы и разметку; менять только контекст | Отложен | Технический gate Cognee не пройден; сопоставимый контекст не гарантирован |
| Сравнить качество трёх типов, основания, SLA, дубли и контекстные ошибки | Не выполнялся | Сравнение было бы невалидным; метрики не выдумывались |
| Измерить задержку поиска/анализа и затраты индексации/обновления | Не выполнялся | Нет пригодной A/B-проекции; замеры #23 не являются стоимостью поиска в сравнении |
| Проверить регрессии #23 | Выполнено анализом | Дефекты перечислены выше; ни один не объявлен исправленным |
| Зафиксировать рекомендацию | Выполнено | Cognee отложить до исправлений и повторного прохождения #23 |

## Условия возобновления

1. Исправить историческую фильтрацию, редакционные метаданные, доказуемую атрибуцию summaries и подтвердить поведение graph completion без незафиксированных предположений.
2. Подтвердить изоляцию проектов в выбранном режиме доступа и воспроизводимость пересоздания/обновления индекса.
3. Повторить #23 на замороженном корпусе и получить пригодный статус технической проекции.
4. Только после этого зафиксировать входы и параметры #24 и сравнить baseline-контекст с Cognee при неизменных детекторе и правилах.

Неисполнение A/B-сравнения здесь является осознанным результатом остановки по протоколу, а не положительным заключением о Cognee. Данных недостаточно, чтобы утверждать наличие прироста качества или прохождение требований пилота.
